Works · Browser AI

2026 AI Experiments

Interactive AI experiments that run locally in the browser. No API keys or server: each one is made to be opened, tested, and reset.

Three places to start: Latent Atlas for semantic search over a real collection, Amnesiac for what happens when a model forgets you mid sentence, and Vantage for policy and tone inside an enterprise tool.

01

CAPTCHA: After Human

Ten proofs that you are human, in a world where drawing is the only evidence left.

Designing a test that has to stay humane while it is being adversarial.

Each stage gives you fifteen seconds on a torn drawing surface with a velocity-responsive pencil, then an independent AI answers the same prompt on the right. Both drawings become 3D artifacts: fingerprint contours, a branching organism, a weathered relic. The last stage asks you to redraw your first gesture from memory.

WebGL · Procedural geometry · Generative drawing · Vite · JavaScript

Open CAPTCHA: After Human

02

Vantage

The customer-care agent that says the right thing, even when it is thinking something else.

Separating what an agent feels from what it is allowed to say.

A speculative customer-care system exploring the distance between emotional reaction and professional response. Vantage gives Alex a private internal voice, then turns that raw reaction into a calm, useful customer message.

Conversational AI · Agent experience · Responsible automation

Open Vantage

03

Mimic

Life sorted by sight, not by name.

Clustering by resemblance when the label is the least reliable field.

CLIP embeds every live iNaturalist photo into visual space, and organisms cluster by resemblance, not taxonomy. Where the feed outruns memory, the atlas forgets: hollow expected forms fill the gaps until reality confirms them.

CLIP (transformers.js) · Three.js WebGPU + TSL · iNaturalist API · Vanilla JS

Open Mimic

04

Latent Atlas

A museum collection, arranged by what a neural network sees.

Search as navigation: finding by meaning when nobody knows the vocabulary.

1,500 Met Open Access works embedded with CLIP and laid out in a WebGPU galaxy by UMAP. Fly through visual similarity, then type a phrase and an in-browser text encoder flies the camera to matches by meaning, not tags.

CLIP (transformers.js) · Three.js WebGPU + TSL · Met Open Access API · Vite · TypeScript

Open Latent Atlas

05

Mirror

An AI that reconstructs a person from almost nothing.

Showing inference happening, so the viewer can see how little it needs.

Five synthetic characters with procedural WebGPU particle portraits. Browse street scenes, talk by voice, and get replies from an on-device Llama model with audio-reactive lip sync. The surveillance metaphor lives in how confidently thin signal becomes a whole person. Every persona is invented, never a real third party.

web-llm (MLC) · Web Speech API · Three.js WebGPU + TSL · Vite · TypeScript

Open Mirror

06

Flatten

A machine that sees in 3D and gets the space wrong.

Designing for a model that is confidently wrong about depth.

Live webcam depth via Depth Anything V2, rebuilt as a broken 3D point cloud. The model's edge hallucinations stretch into visible geometry: smear, confidence, and ghost frames left in on purpose.

Depth Anything V2 · Three.js WebGPU + TSL · Hugging Face Transformers · Vite · TypeScript

Open Flatten

07

Forecast

A machine reading the mood of the species, live.

Putting a live prediction on screen beside how wrong it just was.

GDELT crisis signal drives a WebGPU tension field on the globe. An in-browser LSTM trains on recent volume each session and forecasts the next spike, then narrates headlines as a typewriter voice while the map watches itself get the future slightly wrong.

GDELT API · TensorFlow.js · Three.js WebGPU · Vite · TypeScript

Open Forecast

08

Revision

Every edit to the largest record humanity has ever kept, rippling live.

Making a firehose legible without pretending it is calm.

The global Wikimedia edit firehose drives a real-time WebGPU particle field, where each point of light is a live revision happening right now. Five author archetypes shape the field; the center shows the article being changed this second with edit rate, revert count, and a running narration.

Three.js WebGPU + TSL · Wikimedia EventStream · Vite · TypeScript

Open Revision

09

Amnesiac

An AI you talk to that loses its memory while you talk to it.

Memory as an interface material: what breaks when context decays.

A local LLM on WebGPU with a corruption buffer that rots conversation history in real time. The model genuinely responds to broken memory: the UI and WebGPU substrate decay as coherence falls.

web-llm (MLC) · Three.js WebGPU + TSL · Web Audio · Vite · TypeScript

Open Amnesiac

10

Feral

The planet's living activity, scored in real time.

Turning a continuous data stream into something with a tempo.

iNaturalist sightings drive a generative score and a WebGPU globe. Real animal field recordings are woven into synth voices; a tfjs sequence model learns the order life is being logged and writes the lead line.

Tone.js · TensorFlow.js · Three.js WebGPU · iNaturalist API · Vite · TypeScript

Open Feral

11

Watcher

Every person classified. Every scene assessed. Confidently wrong about all of it.

Surfacing a classifier's confidence so its errors are visible, not hidden.

Florence-2 runs in-browser on a grid of live public street cameras worldwide, tracking subjects with templated surveillance dossiers, dwell-escalating threat scores, and a CRT-treated WebGPU HUD. Real VLM inference; the bureaucracy layered on top is fiction.

Florence-2 (transformers.js) · Three.js WebGPU · Global public camera APIs · Vite · TypeScript

Open Watcher

12

Guise

A camera-led AI transformation study. Guided demo available on request.

Real-time generative video with a person in the loop.

Camera pose locks in, Florence-2 captions what it sees, then FLUX repaints you as viking warrior, marble statue, cyberpunk, or anything you type. Likeness slider, typewriter story beats, and on-demand upscale. Transforms run through a server proxy so the fal key never hits the browser.

Florence-2 (fal.ai) · FLUX Kontext · Clarity upscaler · Vanilla JS

Open Guise
