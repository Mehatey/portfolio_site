design system

The system exists to serve one rule: a figure a machine asserted and a figure a human verified must never look the same. Every token, state, and motion below is downstream of that.

The one rule

Read this before changing anything. Most decisions in this system look arbitrary until you hold them against it.

Fluency is not evidenceWell written prose carrying an unverifiable number is the failure this product exists to prevent. Anything that makes machine output look more finished without making it more provable is a regression.
Attention is the scarce resource, not screen spaceSurfacing everything the agent did is the lazy answer. The system hides what has been proven and ranks what has not. Adding an always visible panel is a cost, not a feature.
Confidence is never displayedModel confidence and token probability measure fluency, not truth. Only measured historical accuracy appears anywhere in this product, and it is always attributed to a source class and a sample size.
Colour never carries state aloneEvery claim state is also distinguished by border style, a glyph, or a written label, because credit teams print memos and because roughly one in twelve male users cannot separate the amber and green states.

Colour

Four semantic families and one accent. The accent is reserved for things the analyst has not yet decided, which is why it reads as attention rather than as brand.

Do not

Do not introduce a fifth semantic colour. If a state needs one, the state model is wrong.

Do not use --pass for a figure the agent proved but a human has not seen. Green means a person is accountable for it, or a deterministic tool produced it. Those are the only two cases.

Type

Three registers, and the split is the argument. Monospace means a machine asserted the value. The document face carries everything a person wrote, including the memo's own headings and field labels. The interface face is for the tool around the document. Nothing a human wrote is ever set in the machine register.

The signature decision in this system. Prose is set in the interface sans. Every figure a machine asserted is set in monospace. The analyst can see which words a human chose and which numbers a machine claimed without reading either.

Do not

Do not set a machine figure below 13px or unlock its baseline. Mono inside prose shifts the line box and the paragraph leading goes uneven.

Do not set analyst written prose in monospace. The distinction stops meaning anything the moment it is used decoratively.

Claim states

Every figure in the memo is in exactly one of six states. Five are visible to the analyst. The sixth, auto, is deliberately quiet: it was proved deterministically and is not the analyst's problem.

$9.14Mauto Proved by a tool without a person. Hairline underline, no colour. One of the 28.
35 monthsopen In the queue, no decision yet. Accent underline plus accent text.
$380,000conflict Two sources disagree. Warn underline, warn wash. The agent will not pick one.
112%unsupported Nothing available can check it. Fail underline, fail wash. Written, never dropped.
$421,300asked Question outstanding with the company. Dashed underline, so it differs from conflict without colour.
$8,412,000accepted A named person is accountable for it, with a timestamp on the receipt.

The state machine

Four actions move a claim. Only two of them close it. Rejecting does not mark a figure wrong, it re-reasons the step and returns a new answer, which may be the same answer.

scroll sideways to follow the flow →

Asked does not block circulation. The memo goes to committee marked conditional rather than waiting on a reply, because blocking on the company is where throughput actually dies.

Components

ComponentPurposeRules
Queue rowOne unresolved claim Always carries three signals: leverage bar, accuracy percentage for its source class, and state chip. Never sorted by document order except in the explicit comparison mode.
Proof panelEvidence for one claim Fixed order: consequence, side by side proof, inline source, track record, actions. The consequence comes first because it decides whether the analyst reads the rest.
Inline sourceThe document region cited Tabbed when a claim cites more than one document. Max height 196px then scrolls. The cited region is always marked. Never the only way to reach the full document.
Accuracy dialMeasured track record Always a button. Always opens the sample behind it, including the rows where the agent lost. Never displays a value the analyst cannot audit.
Margin markerSection level state Count of open figures, or a tick. Clicking jumps to the first open claim in that section.
Status stampMemo disposition Three values only: held, conditional, cleared. Derived from claim states, never set directly.
ReceiptWhat travels with the memo Machine proved, human accepted, open, spot checks, exceptions, attention spent. Generated, never composed.
SheetFull document, queue, calibration Max 680px. Header, body, footer with a provenance note on the left and a ghost Close on the right. Escape always closes. Header and footer are pinned and only the body scrolls, so the line that is the reason the sheet exists is never below the fold.
Boundary blockWhat left the firm's environment Deliberately neutral, --sunk on --rule, never a semantic colour. An outbound lookup is neither a pass nor a warning, it is a fact the security team is entitled to see, and colouring it would assert a judgement the product has not earned. States what was sent and what was not. Appears only on claims that made a call outside the network.
Assumption tagThis is my call, not their fact Dashed border, --faint, sits against the block label. Marks anything inferred about the customer rather than told to us. Never on a figure, only on a design position. If it is on a figure the state model is being used wrongly.

Motion

Four moments. Each carries information the static frame cannot. Anything else does not ship. All of it is suppressed under prefers-reduced-motion.

Reshuffle500ms · 14ms stagger Rows travel to their new rank when the sort changes, so the cost of document order is seen rather than described.
Propagation170ms interval A decision walks down its dependents in order, at the speed an eye moves down a page. Numbers count rather than cut.
Settle500ms wipe A resolved figure closes left to right, so it reads as the claim resolving rather than the page repainting.
Running1150ms loop A re-reasoning step sweeps its status chip, visible from the queue without the panel open.
Seal500ms border The memo is circulated. The card seals and the stamp becomes a time. The only motion about the document rather than a figure.
Do not

No entrance animation on load. No motion on hover beyond a 140ms colour or border change. No spring easing. A credit tool that bounces reads as a toy.

Accessibility floor

RequirementStandard
Text contrast4.5:1 minimum against its own background, verified in browser at six viewports. --faint at 4.6:1 is the floor and nothing lighter carries text.
Type floor10px, and only for uppercase monospace labels with .1em tracking or more.
State encodingNever colour alone. Border style, glyph, or written label accompanies every state.
KeyboardFull review loop without a mouse: ] [ to move, Enter to accept, X to reject, A to ask, Esc to close.
Focus2px accent ring on every interactive element, at 2px offset. Controls inside a container that clips, the sort toggle, the tab strip, the list of 28, draw the ring inside themselves at -2px instead, because an outset ring is cut off there and the control reads as unfocused.
ReachabilityAnything clickable is a real control, never a div or li with a click handler. The 28 proved figures are buttons for this reason: hidden is not the same as withheld, and a row a keyboard cannot reach is withheld.
DialogsA sheet carries role="dialog" and aria-modal, is labelled by its own heading, takes focus when it opens, traps Tab and Shift Tab inside itself, and returns focus to whatever opened it. Without the trap a keyboard user tabs through the rail behind an overlay they cannot reach.
MotionAll animation suppressed under prefers-reduced-motion, in CSS and at four JavaScript call sites.
